# RAD Labs missions

Tutorials for the RAD Labs Holiday Quest (https://labs.raddevelopment.co.za), a free set of holiday coding missions from RAD Academy.

Each mission opens in the micro:bit MakeCode editor with a link like:

```
https://makecode.microbit.org/#tutorial:https://github.com/Chimo-Holdings/rad-labs-missions/m01-name-scroller-v1
```

## Rules for every tutorial

- The last step uses the child's own 4-digit **mission key** (shown on the RAD Labs page) in a `show number` block, so the code they type back is theirs alone. The sum must match the formula in the RAD Labs app (`src/content/missions.ts`).
- Never change a published tutorial file. Copy it to a new version (`-v2`), add it to `pxt.json`, and point the app at the new name, so a child halfway through keeps the old one.
- Every step is a numbered list of single actions, naming the toolbox category each block comes from, and ends with a ```blocks snippet of the finished code for that step (the lightbulb hint).
- Keep images small (800 px wide, under 200 KB) and avoid video.
